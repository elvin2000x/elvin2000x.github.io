Worksheet 1: The AI Task Matrix (Ch 2)

Score one task before you decide how much to trust the output.

The task: __________

Axis 1, what it is. Circle one: pattern work · judgment work · factual work · creative work

Axis 2, cost of an error. Circle one: trivial (a revision) · moderate (an explanation) · high (a relationship, money, or reputation)

The call this produces: - Low cost, pattern or creative: delegate freely, light read. - Moderate cost: delegate, then verify the parts that carry weight. - High cost, or factual with consequences: Director's Due Diligence applies (Worksheet 6).

My decision: __________

Worksheet 6: The Reputational Audit (Ch 14)

Run before any high-stakes output leaves your hands. Check each box only when the answer is a genuine yes.

  • [ ] 1. I have identified every Tier 1 claim (figures, dates, names, attributions) and confirmed each against a primary source.
  • [ ] 2. I have traced the reasoning on every Tier 2 conclusion and the logic holds for this situation.
  • [ ] 3. I have weighed every Tier 3 recommendation against my own professional judgment.
  • [ ] 4. If this falls into a high-stakes category, a second set of eyes has reviewed it.
  • [ ] 5. I have considered whether an undetected error would damage a relationship, a client's interests, or the organization's reputation.
  • [ ] 6. I am prepared to put my name on this and answer for it.

Where the remaining work is (any box unchecked): __________
