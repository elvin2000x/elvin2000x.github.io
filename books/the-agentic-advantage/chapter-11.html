SNIPPET 2Here's the pattern I use for SESSION_STATUS injection:

python
import anthropic
from pathlib import Path

client = anthropic.Anthropic()

def load_session_status():
    status_path = Path(r"C:\Users\you\Documents\config\SESSION_STATUS.md")
    return status_path.read_text(encoding="utf-8")

def run_briefing_agent():
    session_context = load_session_status()

    response = client.messages.create(
        model="claude-sonnet-4-5",
        max_tokens=1024,
        system=[
            {
                "type": "text",
                "text": session_context,
                "cache_control": {"type": "ephemeral"}
            },
            {
                "type": "text",
                "text": "You are the morning briefing agent. Summarize priorities."
            }
        ],
        messages=[
            {"role": "user", "content": "Generate today's briefing."}
        ]
    )
    return response.content[0].text

print(run_briefing_agent())

SNIPPET 3The routing logic doesn't need to be sophisticated. The decision tree is simple:

code
Is this task running more than 20 times per day?
  Yes → Does it require genuine judgment or quality writing?
    No → Haiku
    Yes → Sonnet
  No → Sonnet
Is this task customer-facing and high-stakes?
  Yes → Sonnet minimum, consider Opus
  No → Sonnet

SNIPPET 4For agents that generate long outputs (1,000+ words) implement streaming. Without streaming, your script waits for the entire response befor

python
with client.messages.stream(
    model="claude-sonnet-4-5",
    max_tokens=2048,
    messages=[{"role": "user", "content": prompt}]
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)

SNIPPET 5After provisioning the VPS, the first fifteen minutes establish the security baseline:

bash
# Update system
apt update && apt upgrade -y

# Create non-root user
adduser empire
usermod -aG sudo empire

# Configure SSH key auth
# (copy your public key to ~/.ssh/authorized_keys first)
sed -i 's/#PasswordAuthentication yes/PasswordAuthentication no/' /etc/ssh/sshd_config
systemctl restart sshd

# Configure firewall
ufw allow 22/tcp
ufw allow 80/tcp
ufw allow 443/tcp
ufw enable

SNIPPET 8For each always-on agent, create a service file at /etc/systemd/system/agent-name.service:

ini
[Unit]
Description=Telegram Bot Agent
After=network.target

[Service]
Type=simple
User=empire
WorkingDirectory=/home/empire/agents
ExecStart=/usr/bin/python3 /home/empire/agents/telegram_bot.py
Restart=always
RestartSec=10
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
