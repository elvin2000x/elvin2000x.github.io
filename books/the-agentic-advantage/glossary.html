Glossary

From The Agentic Advantage

Also online, free. This appendix is on the web in copy-and-paste form, kept current, at elvinpeters.com/books/the-agentic-advantage/glossary.

The agentic world moved fast enough to grow its own vocabulary. These are the terms this book leans on, in plain language, so you can read any chapter without keeping a browser tab open. Where a term carries a precise technical meaning and a looser everyday one, I have given you the version an operator actually needs.

Agent. An AI system that pursues a goal by choosing its own next action, calling tools, observing the results, and repeating until the goal is met. The step up from a chatbot that only answers.

Batch API. An asynchronous mode that runs non-urgent jobs at roughly half the standard rate, in exchange for results within hours instead of seconds.

Cascade routing. Sending a request to a cheap model first and escalating to a stronger one only when the cheap answer is not good enough.

CLAUDE.md. A project file Claude Code reads at the start of every session, holding standing context: who you are, how you work, and the conventions of your operation.

Compaction. Summarizing older conversation history so a long-running agent stays inside its context window without losing the thread.

Context engineering. The discipline of deciding what goes into the model's context window on each call, and in what order, so it has what it needs and nothing that distracts it.

Context window. The amount of text a model can consider at once, measured in tokens. Everything the model knows in the moment lives here.

Effort. A dial on some models that trades thinking depth and token spend against speed.

Embedding. A numeric representation of text that lets a system find passages by meaning rather than by exact words.

Eval / golden set. A small, versioned set of test cases with known-good answers, run on every change to catch regressions before they reach production.

Fan-out / fan-in. Splitting a job across several agents that run in parallel (fan-out), then combining their results into one (fan-in).

Guardrail. A rule that keeps an agent inside safe bounds. The reliable ones live in code as well as in the prompt.

Hook. A script Claude Code runs automatically at a defined moment, for example before a tool call, to log, notify, or block.

Human-in-the-loop. A checkpoint where the agent pauses for a person to approve an action before it happens, placed before anything hard to undo.

Idempotency. Designing an action so that running it twice has the same effect as running it once, which makes a retry safe.

MCP (Model Context Protocol). An open standard for pre-built tool servers an agent can connect to, covering common platforms without custom code.

Model tiers. The family of models offered at different capability and cost points: lightweight and fast (Claude Haiku), balanced (Claude Sonnet), and frontier (Claude Opus).

Observability / tracing. The ability to see, after the fact, exactly what an agent did on a run: every tool call, its input, its output, and its cost.

Orchestration. Coordinating several agents or steps so they hand work off to each other cleanly.

Prompt caching. Reusing the model's processing of a stable prefix across calls to cut cost and latency, for as long as that prefix does not change.

Prompt injection. An attack where instructions hidden inside content the agent reads, such as a web page or an email, try to hijack its behavior.

RAG (retrieval-augmented generation). Fetching relevant documents and adding them to the prompt so the model answers from real sources rather than from memory.

ReAct loop. The core agent cycle: reason, act by calling a tool, observe the result, and repeat.

Re-ranking. A second pass that reorders retrieved passages by true relevance, since a similarity search on its own returns plausible-but-wrong hits.

Router. A lightweight model whose only job is to read a request and decide which agent or tier should handle it. The router decides; it does not do the work.

Slash command. A reusable prompt packaged behind a short command in Claude Code.

Subagent. An agent spawned by another agent to handle one piece of the work on its own.

System prompt. The standing instructions that define an agent's role, constraints, and output format, re-read on every call.

Token. The unit models read and bill in, roughly three-quarters of a word.

Tool / tool use. A function you expose to the model. The model decides when to call it and with what arguments, and your code runs it.

tool_choice. The setting that controls whether the model may use a tool (auto), must use some tool (any), must use one specific tool, or may not use tools at all (none).

Trigger-Action-Memory loop. The operator's shape for an agent: something triggers it, it acts through tools, and it writes what it learned to memory for the next run.

Vector database. A store for embeddings that answers the question "what is most similar to this" over a large body of text.

VPS (virtual private server). A small rented cloud computer that runs your agents around the clock, independent of your own machine.

Webhook. An inbound call from an external service that wakes an agent when an event happens, rather than making the agent poll for it.
