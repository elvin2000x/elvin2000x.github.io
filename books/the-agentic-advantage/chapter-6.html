SNIPPET 2The pattern, in code:

python
import json
from pathlib import Path

STATE_FILE = Path("state.json")

def load_state():
    if STATE_FILE.exists():
        return json.loads(STATE_FILE.read_text())
    return {"version": "1.0", "cities_completed": [], "total_leads": 0}

def save_state(state: dict):
    STATE_FILE.write_text(json.dumps(state, indent=2))

# At the top of every agent run:
state = load_state()

# ... do work, update state ...
state["total_leads"] += new_leads_found
state["last_run"] = datetime.utcnow().isoformat() + "Z"

# At the bottom of every agent run:
save_state(state)

SNIPPET 4The right starting point is Chroma. It is free, runs locally as a Python library, requires no server, and integrates directly with the Anthr

python
import chromadb
from anthropic import Anthropic

client = Anthropic()
chroma = chromadb.Client()
collection = chroma.get_or_create_collection("engagement_notes")

def search_memory(query: str, n_results: int = 5) -> str:
    results = collection.query(query_texts=[query], n_results=n_results)
    return "\n\n".join(results["documents"][0])

# Before the agent call:
relevant_context = search_memory("manufacturing company cost reduction")

response = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=2048,
    system=f"You are a research assistant. Relevant context:\n{relevant_context}",

SNIPPET 5Here is the pattern, 15 lines that are the foundation of every context-aware agent in the stack:

python
from pathlib import Path
from anthropic import Anthropic

client = Anthropic()

def build_system_prompt() -> str:
    session_status = Path(
        r"C:\Users\elvin\Documents\Brain\SESSION_STATUS.md"
    ).read_text(encoding="utf-8")
    
    base_prompt = """You are Claude, Elvin's AI collaborator.
You run as part of an autonomous agent ecosystem.
Answer directly. No filler. Use specific numbers."""
    
    return f"{base_prompt}\n\n## Current Project Status\n{session_status}"

def ask(user_message: str) -> str:
    response = client.messages.create(
        model="claude-sonnet-4-5",
        max_tokens=2048,
        system=build_system_prompt(),
        messages=[{"role": "user", "content": user_message}]
    )
    return response.content[0].text

print(ask("what's the status on the book?"))

SNIPPET 6The injection pattern composes. You can inject multiple files:

def build_agent_context(agent_name: str) -> str:
    brain = Path(r"C:\Users\elvin\Documents\Brain")
    
    session_status = (brain / "SESSION_STATUS.md").read_text()
    
    state_file = Path(f"agents/{agent_name}/state.json")
    current_state = state_file.read_text() if state_file.exists() else "{}"
    
    return f"""## Session Status
{session_status}

## Agent Current State
{current_state}"""
