# Tool-Selection Cheat Sheet

*The Systematic Advantage Toolkit*

> **As of: early 2026. This is the one document in the kit designed to expire.** The book keeps product names out of its permanent pages on purpose, because this list moves faster than a book can print. Treat every product below as the current instance of its category. The category is the durable part. Verify the specific tool before you rely on it, and expect this page to be refreshed on the list you got it from.

The question is never "what is the best AI tool." It is "what category of tool does this job need." Match the job to the category first, then pick whatever currently leads that category.

| The job to be done | The category you want | Current instances (early 2026) |
|---|---|---|
| Think, draft, analyze, and converse across almost anything | Frontier chat assistant | Claude, ChatGPT, Gemini |
| Get answers grounded only in your own documents, with citations | Document-grounded notebook | NotebookLM |
| Keep standing context and files for a recurring body of work | Project workspace | Claude Projects, ChatGPT Projects, Gemini Gems |
| Have AI build a working artifact (a spreadsheet, a script, a site) | Agentic workspace | Claude Code, ChatGPT agent mode, Cursor |
| Produce a long, sourced research brief from many pages | Deep-research mode | Deep Research in ChatGPT, Gemini, and Claude |
| Generate or edit images, including compositing onto a reference | Image model | Gemini image generation, Midjourney, Ideogram |
| Generate short video from a prompt or a reference frame | Video model | Veo, Sora, Runway |
| Turn speech into text, or work hands-free | Voice and transcription | Native voice modes; Whisper-based transcribers |
| Connect AI to your other apps and run it on a schedule | Automation platform | Make, Zapier, n8n |
| Write code inside your editor | AI-in-the-IDE | Cursor, GitHub Copilot, Claude Code |

## How to choose within a category

1. **Start with what you already pay for.** A frontier assistant you already have beats a marginally better one you have to learn. Chapter 4's point stands: stop hunting for the best and use what is in front of you well.
2. **Match the model tier to the stakes rather than to the habit.** Use the cheaper, faster model for formatting and simple drafts. Bring the strongest model to reasoning, strategy, and anything high-stakes. That is the effort dial from Chapter 4.
3. **Let the job pick the category, then let recency pick the product.** Leadership in each category changes every few months. Your judgment about which category fits the job does not.

## When to switch tools

Switch when the job changes category rather than when a competitor posts a better benchmark. A new model that scores higher on a test is news. A tool that does a category you could not do before is a readiness question worth acting on. Chapter 16's four questions apply here directly.
